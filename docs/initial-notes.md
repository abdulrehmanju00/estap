# Initial Reference Package Notes

- Supplied files: `index.html` and `styles.css`.
- The HTML links to the local stylesheet using `href="styles.css"` in the original ZIP. The files are now grouped under `reference/`; update nothing in the source capture. The HTML remains an archived reference, not a standalone deployment entry point.
- The HTML includes a large number of live `rays.com.pk` references, external scripts and WordPress-related resources.
- The stylesheet includes external font/icon resources hosted on the Rays domain.
- The capture includes markup for the homepage, not a complete set of independently captured pages or backend source.
- This package intentionally does not attempt to rewrite the original HTML, because rewriting it could alter the visual reference.
